# ccs32clara-discharger

Goal: an open-source (GPL-3.0) **charger-side (SECC)** firmware for the Longood CCS V2L
discharger, built on ccs32clara / ccs32clara-chademo and on the charger logic of uhi22/pyPLC.

**Status:** in development in a private repository; the code will be published here once it
has been validated. This fork currently contains only the upstream ccs32clara-chademo project.
